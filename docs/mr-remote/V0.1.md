# MR Remote — V0.1.0

Base: RustDesk 1.5.3, commit `95cca3f661f635b3cc85c04935fe8d96d8f432ef`.

## Escopo
- Windows x64, Flutter e Rust originais.
- Preservar autenticação, consentimento e criptografia.
- Manter licença AGPL-3.0 e avisos originais.
- Não publicar binários de teste como produção.

## Critérios de aceitação
- [x] Fork e branches main/develop criadas a partir da referência estável.
- [ ] Workflow Windows x64 sem dependência de credenciais de assinatura upstream.
- [ ] Compilar e validar artefato em Windows isolado.
- [ ] Implantar HBBS/HBBR OSS em ambiente autorizado com chave pública configurada.
- [ ] Testar conexão direta e relay entre dois computadores autorizados, mouse, teclado, transferência de arquivos e encerramento da sessão.
- [ ] Verificar falha de autenticação, rejeição de conexão e permissões.
- [ ] Registrar evidências e aprovar antes da distribuição.

## Fluxo
`master` preservada; `main` base estável; `develop` integração; mudanças via PR.
Não incluir senhas, chaves privadas ou dados de clientes no repositório público.
